## NAK's own content checklist (Tipps p. 5, verbatim items)

*"Überprüfen Sie sich auch anhand der Beurteilungskriterien."*

- [ ] Klarheit der Fragestellung
- [ ] Schlüssigkeit und Struktur der Gliederung / des Aufbaus
- [ ] Berücksichtigung der einschlägigen wissenschaftlichen Literatur zum Thema, v.a. zentrale und aktuelle Veröffentlichungen
- [ ] Umfang und Angemessenheit der verwendeten Literatur
- [ ] Eigenständigkeit in Herangehensweise und Erarbeitung des Themas
- [ ] Habe ich einen Praxisbezug hergestellt?
- [ ] Bezugnahme auf Literatur, Belegen von Argumenten, korrekte Wiedergabe von Fakten
- [ ] Verwendung von wissenschaftlicher Terminologie
- [ ] Definition und Klärung von Fachbegriffen
- [ ] Begründung des methodischen Vorgehens
- [ ] Qualität der wissenschaftlichen Argumentation
- [ ] Differenziertheit der Darstellung der Inhalte sowie der Argumentation
- [ ] Eigenständigkeit des Gedankengangs / der Argumentationslinie
- [ ] Gegebenenfalls: Qualität der empirischen Daten
- [ ] Interpretation der empirischen Daten bzw. der verwendeten Quellen
- [ ] Verbindung von Theorie und Empirie
- [ ] Kritische Reflexion der Arbeit / Problembewusstsein (Selbstreflexion: Knackpunkte benennen — wo hatten Sie Schwierigkeiten?)
- [ ] Verständlichkeit / Klarheit der Sprache
- [ ] Schreibstil / Orthografie
- [ ] Formal korrekte Zitation (Einheitlichkeit und Sorgfalt im Umgang mit Quellen, Texten und Daten)
- [ ] Formale Korrektheit der Arbeit (Deckblatt, Verzeichnisse, Inhaltsverzeichnis, Einleitung, Hauptteil, Schluss, alphabetisches Quellenverzeichnis)

## Formal and technical checks

- [ ] 10 text pages ± 10 % (count excludes lists, appendix, external figures, code; self-made tables and graphics count)
- [ ] Times New Roman 12 pt / Arial 11 pt · 2 cm margins · line spacing 1,25 · justified + hyphenation
- [ ] Official Deckblatt fields (Nr., Matrikelnummer, freigegebenes Thema — **exactly as approved** — Studiengang, Zenturie); **no name anywhere** (also check PDF metadata/author field, headers, interview protocols, file name)
- [ ] TOC; list of figures and tables (no sources in it); abbreviation list with no everyday abbreviations; no chapter numbers on lists
- [ ] Roman page numbers for front and back matter, Arabic from 1 for the text
- [ ] Outline: no single sub-points; introduction = chapter 1 without an extra title; Fazit present
- [ ] All figures and tables referenced in the text; cross-reference numbers correct
- [ ] Company named with its legal form (or abbreviation introduced)
- [ ] No Ich/Wir form, no colloquialisms; read aloud once
- [ ] Bibliography: only cited sources, alphabetical, uncategorised, complete, internet sources with access dates, interviews and internal documents included, no statutes (*Gesetzestexte*)
- [ ] Appendix: every internal document, interview protocol (with date, partner, function, topic, **signature**), data and calculation needed for verification; each referenced from the text
- [ ] Sperrvermerk handled via the CIS checkbox (no extra page); redactions noted in footnotes
- [ ] AI: every use logged in the KI-Prozessdokumentation; AI-generated parts marked in the text; if no AI was used → a note in the first footnote
- [ ] Single PDF ≤ 10 MB

## Upload (CIS, by 23:59 on the deadline day)

- [ ] Transferleistung PDF (incl. appendix)
- [ ] Selbstreflexion (separate document, filled, ~2000 characters without spaces, chapter references, Ich-Form; mention teamwork if applicable)
- [ ] Eigenständigkeitserklärung (signed, with name, separate)
- [ ] KI-Prozessdokumentation (if AI was used)
- [ ] Workload field filled in (realistic hours)
- [ ] Status changed to **"abgegeben"** → screenshot saved; confirmation email received
- [ ] Remember: **no changes possible after upload**
